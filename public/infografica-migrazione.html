Le 6 fasi
FASE 0

🧰 Preparazione 30 min

  • Backup del database (Supabase → Backups)
  • Inventario dei segreti (da reinserire)
  • Congelo inserimenti: finestra di 2-3 ore
  • Scelta account: Gmail nucleo (consigliato) o @dipvvf.it
FASE 1

🐙 GitHub

  • Creare account o Organization del nucleo (sopravvive ai ricambi di persona)
  • Transfer del repo (non copia file!): mantiene storia e redirect
  • Aggiornare secrets Actions con i valori Supabase nuovi
  • Reinstallare la GitHub App di sviluppo assistito
FASE 2

🗄️ Supabase più delicato

  • Opz. A — Transfer: invitare il nuovo owner → tutto resta uguale (URL e chiavi invariati)
  • Opz. B — Nuovo progetto: schema + migrazioni + dump dati (incluse le password di auth)
  • Site URL = nuovo indirizzo Pages
FASE 3

🤖 Render (bot)

  • Nuovo account con email nucleo (non "sign in with GitHub")
  • Build npm install · Start node bot/telegram-bot.mjs
  • Reinserire le 3 variabili (URL e service key nuove)
  • Spegnere il vecchio SOLO dopo il collaudo
FASE 4

✈️ Telegram

  • @Usar_veneto_bot non cambia: il token resta valido
  • I collegamenti utente (chat_id) sono nel database: nessuno ricollega nulla
  • Opzione: nuovo bot "ufficiale" del nucleo se serve identità separata
FASE 5-6

🌐 Sito, dati e persone

  • GitHub reindirizza il vecchio URL: le PWA installate continuano a funzionare
  • Comunicare il nuovo link (Telegram) + reinstall PWA consigliato
  • Pulizia: eliminare i 50 account di prova prima dei dati veri
  • Futuro: dominio proprio (~10 €/anno) = niente più migrazioni visibili
Regole d'oro
Parallel run — il vecchio resta acceso finché il nuovo non è collaudato: login, allerta end-to-end, /ferie del bot.
Mai a mano i dati — il DB si trasferisce con gli strumenti (transfer o dump SQL): 250 profili copiati a mano = errori sicuri.
Segreti mai in chat — token e chiavi si reinseriscono a mano nelle piattaforme nuove, mai scritti in chat o file.
@dipvvf.it? Verificare prima — la posta VVF filtra le email di terze parti (già successo con Supabase): per gli account tecnici meglio il Gmail del nucleo.
